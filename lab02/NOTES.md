git - это система контроля версий ,а github - это веб сервис для хранения репозиториев
diff это неидексованные изменения , dif staged измененияя которые будут вклчены в комит
git status - показывает изменения с последнего комита
ветка это ответвление от проекта которое позволяет писать код который не влияет на main и вы можете не рисковатиь основным кодом
при новом комите в ветке она переключается на последние изменения (не понял вопрос,происходит так же как и в основной)
при слияние ветки в целевую она переносит туда изменения(например написал код в ветке который заработал и нужно теперь ввести те же изменения в основную ветвь )
